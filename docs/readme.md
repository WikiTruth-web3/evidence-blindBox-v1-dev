# 项目简介

**Evidence Market** 是一个**一个将“犯罪证据”转化为可交易资产的去中心化情报市场**，是 SEC 举报人计划 (SEC Whistleblower Program) 的 Web3 数字化升级版, 基于 **Oasis Sapphire**（具备 TEE 隐私计算能力的 EVM 兼容公链）构建。

通过 Evidence Market，吹哨人可以将**有风险证据** 转化为链上资产，通过交易市场流通变现，获得经济回报，从而激发更多人参与正义行动的积极性。

## 核心产品

Evidence Market 包含两大核心市场：

**1. Evidence Blind Box (证据盲盒)**：证据被铸造成 Evidence Blind Box 投入市场流通，能否变现依赖是否能成功交易，如果没有则证据公开，如果成功交易则会产生一笔无限增长的**延迟披露溢价 (Delay Premium)**，没有人能够承担此费用，最终依然会将证据公开。

**2. Bounty Token (悬赏令牌)**：将传统的线下悬赏通告、线人制度，升级为了流程透明、匿名隐私、无需信任的去中心化情报需求池。在架构设计上采用了更加灵活和现实的**一池对多提交**模式，最终的奖金分配将由发布者**根据每个提交者的实际贡献价值，自行决定奖金的分配比例**。

得益于 Web3 智能合约特性，以及代币经济模型，Evidence Market 解决了传统犯罪举报渠道中存在的信任崩塌、信息不透明、举报人信息遭泄露、举报人安全无保障与激励缺失等问题。

## 项目特点

**1. 匿名隐私保护**：利用 Oasis Sapphire 的 TEE 隐私计算能力，确保所有交易记录、用户身份信息、举报内容等敏感数据在链上不可被读取、篡改或泄露，从根本上保护吹哨人的安全和隐私。

**2. 无需信任的经济激励**：通过智能合约自动执行，确保奖励分配公平、透明、可追溯，让吹哨人能够安心获得应有的回报，并有效避免传统模式中可能出现的跑路、拖欠奖励等信任风险。

**3. 资产化、可流通的证据**：通过 Evidence Blind Box 机制，将证据转化为可交易的链上资产，增加了证据的流动性和经济价值，同时也为资金提供了一个投机获取未来披露溢价（Delay Premium）的机会。

**4. 去中心化的情报机制**：Bounty Token 机制打破了传统中心化机构对情报需求的垄断，形成一个去中心化的、公开透明的情报收集与悬赏市场。

**5. 经济模型创新**：引入“延迟披露溢价”概念，利用智能合约设计了一种独特的经济模型，既能激励早期购买者承担风险，又能确保最终奖励给真正推进案件进展的人，同时防范无尽的债务无限积累。
